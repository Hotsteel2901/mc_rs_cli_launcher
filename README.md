# A rust base minecraft CLI-Only launcher

## how to use:

1.clone this repo:
```bash
git clone --depth=1 https://github.com/Hotsteel2901/mc_rs_cli_launcher.git
```
2.cd into:
```bash
cd mc_rs_cli_launcher/
```
3.build it:
```bash
cargo build --release
```
4.use it:
```bash
cd target/release/
./mc-launcher -h #get the guides.
```
